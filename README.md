# Мерч-Империя

Экономическая игра для класса. Ученик запускает школьный бизнес по печати футболок и за 16 игровых месяцев растит его от гаража до капитала в 1 000 000 ₽.

## Как играть на уроке

1. Открыть файл `index.html` в любом браузере (Chrome, Edge, Firefox, Safari). Интернет нужен только для шрифтов, без него игра тоже работает.
2. Ввести имя и нажать «Начать игру».
3. Каждый месяц: событие → планирование (цена, выпуск, реклама, развитие, финансы) → итоги месяца. После каждой главы идёт проверка знаний из трёх вопросов.

**Урок 1** — месяцы 1–8 (главы «Гараж» и «Первый магазин»). **Урок 2** — месяцы 9–16 (главы «Рост» и «Империя»). Игра сохраняется сама. На втором уроке достаточно открыть её на том же компьютере и нажать «Продолжить». Если компьютер другой, на экране конца урока 1 есть код сохранения: его можно скопировать и загрузить кнопкой «Загрузить код сохранения».

В конце ученик получает строку с результатом (имя, капитал, звание, баллы за вопросы), которую можно отправить учителю.

## Чему учит игра

Прибыль и маржа, закон спроса, конкуренция, сезонность, издержки, постоянные и переменные расходы, налоги, труд и зарплата, риск и доходность, кредит и процент, инфляция, вклад и сложный процент, валютный курс, диверсификация, эффект масштаба, экономический цикл, капитал. 12 вопросов в четырёх викторинах и словарик терминов.

## Устройство проекта

| Файл | Что внутри |
| --- | --- |
| `src/engine.js` | экономическая модель: спрос, затраты, налоги, кредит, вклады |
| `src/data.js` | 16 событий, словарик, вопросы викторин |
| `src/ui.js` | интерфейс, экраны, сохранение, звук |
| `src/style.css` | дизайн, светлая и тёмная тема |
| `build.py` | собирает всё в один файл `index.html` (`python3 build.py`) |
| `tools/` | скрипты, которыми проверялся баланс игры |

Баланс проверен автоматическими прогонами: аккуратная игра с расчётом цены даёт капитал около 1,1 млн ₽, средняя около 0,75 млн ₽, пассивная около 0,5 млн ₽.
