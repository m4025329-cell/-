# Карта Тулы (концепт)

Отдельная живая карта города для игры «Первый столик». В саму игру пока **не подключена**: это проверка идеи. Открывается как обычная страница: `city-map.html` (один файл, шрифты внутри, без интернета).

## Что на карте

- Схема города «по мотивам Тулы»: Упа и Тулица, железная дорога с вокзалом, Кремль, парк с колесом обозрения, рынок, университет, завод, спальные районы, частный сектор, окрестности. Масштаб условный, названия заведений вымышленные.
- Десять районов с цифрами, согласованными с моделью игры: состав гостей по пяти сегментам, поток людей по часам, сезонность, аренда, конкуренты, рекламные каналы, часы работы.
- Живой город: прохожие по цветам сегментов, машины, автобусы, поезда (на вокзале останавливаются), лодка, утки, птицы, дым труб, колесо обозрения, облака, дождь, снег, туман.
- Время суток (ночью горят окна и фонари), 16 месяцев игры (сезоны: снег, весна, лето, золотая осень, новогодняя ёлка и лёд на прудах).
- Слои: «Районы», «Гости», «Аренда», «Реклама», «Конкуренты», «Подписи». Панель района (на телефоне шторка): состав гостей, график потока с часами работы, аренда, рекламные каналы с охватом, сравнение «если открыть кафе здесь».
- «Экскурсия» на девять остановок: сама меняет время суток, месяц и погоду.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `src/geo.js` | река, рельсы, узлы районов, магистрали, мосты |
| `src/data.js` | районы, сегменты, кривые потока, реклама, часы работы, конкуренты, достопримечательности |
| `src/gen1.js`, `gen2.js`, `gen3.js` | генерация города (маска занятости, улицы, здания, парки, окрестности) |
| `src/render1.js`, `render2.js` | рисование земли, воды, дорог, зданий, деревьев (наклонный вид, тени) |
| `src/life.js` | люди, транспорт, поезда, погода |
| `src/core.js`, `app.js` | кэш статичного слоя, ночные огни, камера, оверлеи, подписи |
| `src/ui.js`, `style.css`, `body.html` | интерфейс |
| `build.py` | собирает `city-map.html` и `dist/fragment.html` (для публикации) |

Пересборка: `python3 map/build.py`.

## Как связать с игрой, когда придёт время

1. Выбор места кафе: игроку показывают карту, он выбирает район. Аренда и поток района заменяют общие числа города.
2. Реклама привязывается к районам: охват канала = сумма долей сегментов района × таблица охватов игры.
3. Часы работы в игре (9–18, 8–21, 8–23) считаются по кривой потока района, а не по общему коэффициенту.
4. Конкуренты на карте берутся из тех же данных, что и в игре.

## Что проверено и что нет

Проверено в браузере с эмуляцией: рисование на 6 размерах экрана, жесты (сдвиг, щипок, касание, шторка), ползунки, смена сезона и погоды, ночь, экскурсия, время кадра (около 7–13 мс на компьютере). На настоящих телефонах и в Safari не запускалось. Цифры районов учебные, это не статистика города.
