# Как поставить «Первый столик» как приложение

Игра работает тремя способами. Выбирайте самый простой для вас.

| Способ | Для кого | Что нужно | Работает без интернета |
| --- | --- | --- | --- |
| 1. Открыть файл `index.html` | Любой компьютер или телефон | Только файл | Да |
| 2. Установить из браузера (PWA) | Телефоны Android и iPhone, компьютеры | Ссылка на игру, которая начинается с `https` | Да, после первой установки |
| 3. Установить файл `Pervyi-stolik.apk` | Телефоны Android | Скачать файл и разрешить установку | Да |

## Способ 1. Файл `index.html`

Скачайте файл и откройте его в браузере двойным щелчком (на телефоне: «Открыть в» → Chrome). Игра сохраняет прогресс в этом браузере. Установить значок таким способом нельзя: для этого нужны способы 2 или 3.

## Способ 2. Установка из браузера (рекомендуется)

Откройте игру по ссылке, которую дал учитель или владелец проекта. Адрес должен начинаться с `https`.

### Android (Chrome, Edge, Samsung Internet)

1. Откройте ссылку в Chrome.
2. На титульном экране появится карточка «Установите игру как приложение», нажмите «Установить». Если её нет, нажмите три точки справа вверху → «Установить приложение» (или «Добавить на главный экран»).
3. Подтвердите. Значок «Первый столик» появится среди приложений.
4. Откройте значок: игра запустится на весь экран, без адресной строки.

### iPhone и iPad (только Safari)

1. Откройте ссылку в **Safari**. В Chrome и других браузерах на iPhone нужного пункта нет.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Прокрутите список и выберите «На экран «Домой»», затем «Добавить».
4. Откройте значок с главного экрана.

### Компьютер (Chrome, Edge)

1. Откройте ссылку.
2. Справа в адресной строке нажмите значок установки (экран со стрелкой) или в меню выберите «Установить «Первый столик»».
3. Игра откроется в своём окне, как обычная программа.

### Как проверить, что всё хорошо

- Выключите интернет (режим «в самолёте») и откройте значок игры. Она должна открыться и сохранённая партия должна быть на месте.
- Когда выходит обновление игры, внутри появится сообщение «Вышла новая версия игры». Закройте приложение и откройте снова.

## Способ 3. Файл `Pervyi-stolik.apk` (Android)

Файл лежит в папке `play/` проекта. Он нужен, если у вас нет ссылки `https` или вы хотите приложение «как из магазина».

1. Скачайте `Pervyi-stolik.apk` на телефон (в репозитории откройте файл и нажмите «Download raw file» или иконку скачивания).
2. Откройте скачанный файл. Телефон попросит **разрешить установку из этого источника** (обычно для браузера или «Файлов»). Разрешите.
3. Если Google Play Protect пишет, что приложение неизвестно, это нормально: приложение не из магазина. Нажмите «Всё равно установить» (в некоторых телефонах: «Подробнее» → «Всё равно установить»).
4. Откройте «Первый столик» среди приложений.

Подпись файла (чтобы убедиться, что это тот самый APK): отпечаток сертификата SHA-256

```
c3cdd4090bc269bd7d7c58d0d6cd8af043889b030537c277bca8aecb6b3a95dc
```

Проверить на компьютере: `apksigner verify --print-certs Pervyi-stolik.apk`.

**Важно.** Приложение собрано и подписано без Android Studio. Проверены манифест, подпись, содержимое файла, а также работа игры в окне, которое имитирует приложение (в браузере Chromium). **На настоящем телефоне или в эмуляторе Android оно не запускалось.** Если оно не установится или вылетит, пришлите марку телефона и версию Android, а пока используйте способ 2.

Ключ подписи хранится только у того, кто собирал файл. Если его потерять, новую версию придётся ставить поверх только после удаления старой. Перед удалением сохраните код или файл работы: данные игры лежат внутри приложения и удаляются вместе с ним.

## Где лежат данные и как их сохранить

Прогресс хранится на устройстве: в браузере, в установленном приложении PWA или в приложении APK. Это три разных хранилища, они не связаны друг с другом. Если играли в браузере, а потом установили приложение, партию нужно перенести кодом: «Меню» → «Код сохранения» → «Скопировать», затем в приложении «Загрузить код». В приложении APK код можно отправить кнопкой «Скачать файлом» (откроется системное окно «Поделиться»).

## Для владельца проекта: как выложить игру по ссылке (бесплатно)

Самый простой способ: **GitHub Pages**.

1. Откройте репозиторий на GitHub → «Settings» → «Pages».
2. В разделе «Build and deployment» выберите «Deploy from a branch».
3. Ветка: та, где лежит папка `cafe` (после слияния — `main`), папка `/ (root)`. Нажмите «Save».
4. Через минуту-две вверху страницы появится адрес вида `https://<имя>.github.io/<репозиторий>/cafe/`. Этот адрес и дайте ученикам. Он открывает игру и позволяет её установить.
5. Проверка: откройте адрес на телефоне в Chrome. Должна появиться карточка «Установите игру как приложение».

Если адрес не открывается, подождите несколько минут (первая публикация идёт дольше). Если страница открывается без стилей или установка не предлагается, проверьте, что открыт именно `.../cafe/` и ссылка начинается с `https`.

Любой другой хостинг статических страниц подойдёт так же: нужно положить рядом файлы `index.html`, `manifest.webmanifest`, `sw.js` и папки `icons`, `screens`.

## Если что-то не работает

| Проблема | Что сделать |
| --- | --- |
| В Chrome нет пункта «Установить» | Адрес не `https`, или игра уже установлена, или вы в режиме инкогнито. Откройте ссылку в обычной вкладке |
| На iPhone нет «На экран «Домой»» | Откройте ссылку именно в Safari |
| Приложение показывает старую версию | Закройте его полностью и откройте снова. Если не помогло, откройте ссылку в браузере и подождите, пока появится сообщение об обновлении |
| Пропала партия | Вы открыли игру в другом хранилище (другой браузер, установленное приложение вместо вкладки). Загрузите код сохранения |
| APK не ставится | Разрешите установку из неизвестных источников для приложения, через которое открываете файл. Проверьте, что версия Android 7.0 или новее |
