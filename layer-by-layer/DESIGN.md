# Дизайн «Слоя за слоем»

Дизайн и анимации сделаны по правилам плагина **UI UX Pro Max** (репозиторий `nextlevelbuilder/ui-ux-pro-max-skill`). Из него использовались каталоги стилей, шрифтов, цветов, анимаций, диаграмм и UX-правил, а также его чек-лист перед сдачей. Плагин даёт общие рекомендации, поэтому конкретные решения ниже приняты с учётом темы (3D-печать), аудитории (8–9 класс) и условий (школьный компьютер, один HTML-файл, русский язык).

## Идея

Игра про печать слоями, значит и интерфейс собран из слоёв.

- **Мотив слоя.** Полосы-слои в логотипе, в индикаторе прогресса, в башне итогов, в самом принтере, который печатает деталь слой за слоем.
- **Тактильный «пластилин» (claymorphism).** Крупные скругления, плотные контуры, «выдавленный» нижний край у кнопок и карточек (`box-shadow: 0 4px 0 …`). Кнопка при нажатии честно «продавливается».
- **Цвета катушек.** Палитра товаров совпадает с цветами пластика: оранжевый, голубой, розовый, зелёный, фиолетовый. Один и тот же цвет встречается у катушки на принтере, в карточке товара, на графике спроса и в разбивке итогов.
- **Фон «миллиметровка».** Тонкая сетка стола принтера под всем интерфейсом.

## Что взято из плагина, а что изменено

| Правило плагина | Как применено |
| --- | --- |
| Стиль claymorphism / tactile depth для игрового интерфейса | Карточки, кнопки, чипы, ползунки |
| Токены цвета с парой «фон + текст на нём», отдельно для светлой и тёмной темы | Все цвета заданы переменными `--…` в `:root`, тёмная тема включается через `prefers-color-scheme` и вручную (`data-theme`) |
| Контраст текста от 4,5:1, элементов интерфейса от 3:1 | Проверяется скриптом `tools/contrast.js` в обеих темах |
| Иконки только SVG, никаких эмодзи | 55 иконок в одном наборе (обводка 2, скруглённые концы), вся графика игры нарисована SVG |
| Цель касания не меньше 44 px | Кнопки, ползунки, вкладки, шаги «минус» и «плюс» |
| Анимация только `transform` и `opacity`, 150–400 мс, одна-две ключевые анимации на экран | Токены движения, ниже |
| Бесконечные анимации только для процесса (печать, курсор терминала) | Принтер при печати, вращающаяся катушка, мигающий курсор |
| `prefers-reduced-motion` | Анимации сводятся к нулю, экран «Принтеры работают» и конфетти пропускаются, числа не «набегают» |
| Видимый фокус, порядок Tab, ссылка «К содержимому» | `:focus-visible` с тройным контуром, переносы фокуса на заголовок при смене экрана |
| Подсказки состояний для скринридера | `aria-live` у сцены и подсказок, `role="status"` у ответов викторины, `role="alert"` у ошибок загрузки |
| Обучение можно пропустить | Кнопки «Пропустить пролог», «Сразу к делу», «Пропустить» в калибровке |
| Адаптив 375, 768, 1024, 1440 | Проверяется на 360, 390, 768, 1024, 1280 и 1440 px |

**Что пришлось заменить.** Для игровой темы плагин предлагает пару Russo One + Chakra Petch. Chakra Petch без кириллицы, поэтому заголовки набраны шрифтом **Tektur** (технический, с полной кириллицей), а текст шрифтом **Golos Text**. Оба есть в каталоге шрифтов плагина.

## Токены

Светлая и тёмная темы заданы одними и теми же именами.

| Назначение | Светлая | Тёмная |
| --- | --- | --- |
| Фон страницы `--ground` | `#EDF0F8` | `#0C1024` |
| Карточка `--surface` | `#FFFFFF` | `#171C3A` |
| Текст `--ink` | `#121A36` | `#EEF1FF` |
| Второй текст `--ink-2` | `#39446A` | `#C2CAEC` |
| Контур карточки `--edge` | `#CDD5EA` | `#2C3562` |
| Контур элементов управления `--edge-strong` | `#7482B0` | `#6E7CB8` |
| Бренд (оранжевый пластик) `--brand` | `#FF7A2F` | `#FF8F4D` |
| Прибыль / убыток | `#0B6A3A` на `#D8F4E3` / `#B3202A` на `#FFE1E1` | `#6FE7A8` на `#12392A` / `#FF9AA0` на `#4A1D26` |
| Подсказка / предупреждение | `#2A40B5` на `#E0E8FF` / `#7A4C00` на `#FFF0C9` | `#B0BEFF` на `#1E2A66` / `#FFD27A` на `#493912` |
| Катушки | оранжевый, голубой `#0E9DBD`, розовый `#E8428C`, лайм `#46A024`, фиолет `#7B61F5` | светлее на 15–25% |

Радиусы: карточка 20, элемент управления 14. Боковое поле 16 px на всех ширинах.

## Шрифты

| Роль | Шрифт | Где |
| --- | --- | --- |
| Заголовки, крупные числа | Tektur | `h1`–`h4`, цифры капитала, названия кнопок |
| Текст | Golos Text | Всё остальное |
| Терминал, код сохранения | JetBrains Mono | Экран принтера в прологе, код сохранения |

Все три шрифта лежат в `fonts/` в формате woff2 (кириллица, латиница и знак ₽) и **вшиваются в `index.html`** при сборке. Игра выглядит одинаково без интернета и не ходит на сторонние серверы.

## Движение

Токены:

| Токен | Значение | Для чего |
| --- | --- | --- |
| `--d-fast` | 120 мс | нажатие, наведение |
| `--d-base` | 220 мс | смена цвета, раскрытие |
| `--d-enter` | 380 мс | появление экранов и карточек |
| `--d-exit` | 240 мс | уход |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | появление |
| `--ease-in` | `cubic-bezier(.55,0,1,.45)` | уход |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | «пружинка» у наград, значков, флажков |

Ключевые анимации:

- **Принтер.** Слои детали печатаются по одному (каждый прорастает слева направо), портал поднимается ступенями по числу слоёв, головка ходит туда-обратно, катушка вращается. Цикл повторяется каждые 3,9 секунды, чтобы все принтеры на экране работали синхронно.
- **Калибровка стола.** Сопло плавно следует за ползунком, линия пластика меняется в реальном времени: тонкая и рваная при высоком сопле, раздавленная при низком, ровная при попадании.
- **Итоги месяца.** Прибыль «набегает» цифрами, строки разбора и их полоски растут по очереди с задержкой 50 мс, в башню слоёв добавляется новый слой.
- **Пролог.** Строки терминала Фила печатаются по одной, дорога к «Технопарку» прорисовывается, флажки с отметками 250, 500 и 750 тысяч поочерёдно «втыкаются» в дорогу.
- **Выбор в сцене.** Иконка сцены выпрыгивает при входе, а чипы последствий (деньги, репутация, изменения спроса) появляются по одному с пружинкой.
- **Финал.** Конфетти на холсте (отключается при `prefers-reduced-motion`), башня слоёв и график капитала.
- **Остальные экраны.** Одно мягкое появление `rise` (сдвиг на 14 px и проявление), без постоянного движения.

## Графика

Всё нарисовано в коде и масштабируется без потерь:

- **Принтер** с настраиваемым числом слоёв, цветом катушки, состояниями «работает», «простаивает», «выключен».
- **Пять товаров** (брелок, подставка, фигурка, запчасть, прототип), их миниатюры и модели на принтере.
- **Аватары** всех персонажей (Фил, Пётр Семёнович, Лиза, Макс, Нина Павловна, Олег, Артём Викторович, Ирина Сергеевна, МегаПринт) с несколькими выражениями лица: радость, тревога, злость, удивление и другие.
- **Сцены пролога:** кабинет с принтером под простынёй, дорога к «Технопарку», стопки монет.
- **Графики:** башня слоёв (ширина слоя по выручке, цвет по прибыли), капитал по месяцам с линией цели, кривая спроса в каждой карточке товара.

## Доступность

- Контраст проверен скриптом в обеих темах (`node tools/contrast.js`): 4,5:1 для текста, 3:1 для границ и значков.
- Информация не передаётся только цветом: у прибыли и убытка есть знак и слово, у штриховки башни есть подпись.
- Всё управляется с клавиатуры. Ползунки с кнопками «минус» и «плюс», варианты выбора кнопками, модальные окна ловят фокус и возвращают его.
- Заголовок каждого экрана получает фокус при смене экрана, динамические блоки объявляются через `aria-live`.
- Звук выключен по умолчанию, любое событие дублируется текстом.

## Адаптив

Две точки перестройки: 960 и 640 px.

- До 960 px: колонки превращаются в одну, иллюстрации пролога и калибровки уходят **наверх**, панель «Печать» делится на блоки в порядке важности (часы печати, режим, товары, реклама, прогноз).
- До 640 px: показатели в шапке идут по два в ряд, шапка перестаёт «прилипать», «Запустить печать» остаётся в нижней панели действий, карточки итогов по товарам превращаются в сетку 2×2, принтеры на экране печати идут по два в ряд.

## Как проверяется дизайн

| Скрипт | Что проверяет |
| --- | --- |
| `tools/contrast.js` | пары «текст на фоне» в обеих темах |
| `tools/e2e.js` | полное прохождение в браузере на нужной ширине и теме, снимки экранов, наложение текста, выход за край экрана |
| `tools/layout.js` | вёрстка при максимальной нагрузке (8 принтеров, все товары, заказы, долги) на 5 ширинах в двух темах |
| `tools/a11y.js` | клавиатура, фокус, подписи |
| `tools/anim.js` | кадры анимации принтера на титульном экране (проверка движения) |
