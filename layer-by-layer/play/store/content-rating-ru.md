# Анкета для возрастного рейтинга (IARC) и целевая аудитория

## Анкета IARC (Play Console → «Политика» → «Рейтинг контента»)
Категория: «Игра».

| Вопрос | Ответ |
|---|---|
| Насилие, кровь, жестокость | Нет |
| Сексуальный контент и нагота | Нет |
| Нецензурная лексика | Нет |
| Наркотики, алкоголь, табак | Нет |
| Азартные игры (в том числе симулируемые) | Нет. В игре есть события со случайным исходом (грант, ярмарка), но нет ставок, ставок на деньги и «казино» |
| Страх, пугающие сцены | Нет |
| Пользователи могут общаться друг с другом | Нет |
| Обмен личной информацией, геолокация | Нет |
| Встроенные покупки, реклама | Нет |
| Контент, созданный пользователями | Нет |

Ожидаемый результат: «Для всех» / PEGI 3 (оценку выставляет сама анкета).

## Целевая аудитория («Политика» → «Целевая аудитория и контент»)
Игра сделана для школьников 8 класса, поэтому подходящий выбор: **13–15, 16–17 и 18+**.
Если выбрать возрасты младше 13 лет, Google применит политику для семейных приложений («Семейная программа»): игра ей соответствует (нет рекламы, нет сбора данных), но анкета станет длиннее. Выбирай младшие группы только если уверен, что нужно именно это.

Приложение **не** предназначено в первую очередь для детей, поэтому добавлять его в «Семейную программу» необязательно.

## Прочие декларации
- Реклама: «Нет».
- Доступ к приложению: все функции доступны без входа и без аккаунта.
- Финансовые функции: «приложение не предоставляет финансовых услуг» (это игра и обучающая симуляция, но не реальные займы).
- Правительственное приложение, новости, здоровье: «Нет».
